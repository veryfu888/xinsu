# 心訴

悶心事就來悶心訴。六爻、八字、紫微、奇門、合婚、風水、塔羅，全部在你的裝置上計算，不會把心事送到伺服器。

內容僅供娛樂與自我反思，非專業建議。

## 圖片與字型來源

- 塔羅牌面：Pamela Colman Smith 1909 原畫（公有領域）。掃描整理：Saskia Jansen，經 Wikimedia Commons 取得。
- 牌背、分頁圖示、橫幅、羅盤與卦象裝飾、網站圖示、銅錢圖：心訴原創繪製。
- 內文字型：霞鶩文楷 TC（SIL Open Font License）。缺字「稊」「胏」取自思源宋體（SIL Open Font License，1.1 版），補字字型已更名為 Xinsu Supplement。
